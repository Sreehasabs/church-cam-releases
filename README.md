# Church Cam releases

Apple-notarised builds of Church Cam for macOS. Church Cam checks this page for updates by itself.

- **Church-Cam-<version>-mac.zip**: Macs on macOS 13 or newer (Apple Silicon and Intel)
- **Church-Cam-<version>-monterey-intel.zip**: Intel Macs on macOS 12 Monterey

Install: unzip, drag Church Cam into Applications, open it. The source code is private.
